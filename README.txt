САЙТ «СВОЙ КРУГ» v2

Структура:
  index.html       — главная страница (шрифты встроены, работает офлайн)
  logo-light.png   — логотип
  photos/          — фотографии команды
  posters/         — постеры фильмов

Как добавить постер:
  1. Положите файл в posters/
  2. В index.html найдите нужный фильм по названию
  3. Замените <div class="poster-ph">...</div> на:
     <img src="posters/имя_файла.jpg" alt="Название">

Карусель:
  • Стрелки ←→
  • Горизонтальный свайп (трекпад, тач)
  • Перетаскивание мышью
  • Клик на постер — переворот с информацией о фильме
